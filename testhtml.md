Transform this existing HTML/CSS/JavaScript page into a premium, cinematic, modern web experience.

First understand the existing structure, content, data, components, and functionality. Then enhance the visual experience without rebuilding the page from scratch.

OBJECTIVE

Make the page feel alive, polished, immersive, and professionally designed rather than static.

Use cinematic UI techniques such as:

- Smooth entrance and exit animations
- Progressive content reveals
- Subtle camera-like zoom and pan
- Depth and layered parallax
- Focus/spotlight on important elements
- Animated counters and data
- Progressive chart/graph drawing
- Staggered card and section reveals
- Smooth transitions between sections
- Subtle shadows, gradients, glow and depth
- Micro-interactions for buttons, cards and controls

DESIGN

Maintain the existing brand, content and purpose of the page.

Improve:

- Visual hierarchy
- Spacing
- Typography
- Depth
- Contrast
- Composition
- Information focus
- Overall polish

The experience should feel like a premium enterprise/product website or product film.

Keep animations elegant, restrained and purposeful.

AVOID

Do not use excessive:

- Neon/cyberpunk effects
- Particles
- Bouncing
- Spinning
- Flashing
- Random movement
- Dramatic zooms
- Glassmorphism
- Gaming-style effects

Do not animate everything at once.

Always maintain readability.

IMPORTANT

Preserve all existing:

- Content
- Data
- Text
- Charts
- Forms
- Buttons
- Navigation
- Filters
- Interactions
- JavaScript functionality

Do not invent data or change the meaning of the page.

Use only HTML, CSS and Vanilla JavaScript unless the existing project already depends on another library.

Prefer performant CSS transforms and opacity animations.

Make the page responsive, with the desktop/laptop experience as the primary target.

CINEMATIC PRINCIPLE

Think of the page as a scene rather than a collection of components.

Create a clear visual journey:

INTRODUCE → FOCUS → REVEAL → DISCOVER → CONCLUDE

At any moment, there should be a clear visual focal point.

The final result should look intentionally designed and cinematic, not simply "animated".

Before finishing, review the page and remove any animation that feels unnecessary, distracting, or artificial
